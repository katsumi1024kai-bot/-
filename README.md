# つづくダイエット

継続することに焦点を当てた、シンプルなダイエット記録サイトです。サーバーやビルド不要の静的サイト（HTML / CSS / JS のみ）で、記録データはブラウザの `localStorage` にのみ保存されます。

## 継続のための工夫

- **連続記録日数（ストリーク）表示**: 記録するたびにカウントし、途切れると0に戻ります。
- **実績バッジ**: 1日・3日・7日・14日・21日・30日・50日・100日・200日・365日の連続記録で解除される10種のバッジ。一度解除すると記録が途切れても消えません。
- **記録カレンダー（ヒートマップ）**: 直近約17週間分の記録状況を一覧表示。自己ベスト（最軽量）の日には★が付きます。
- **目標体重と進捗バー**: 開始体重・現在体重・目標体重から進捗率を自動計算。
- **体重推移グラフ**: 記録した体重の推移と目標ラインを折れ線グラフで表示。
- **応援メッセージ**: ストリークや記録状況に応じて内容が変わる励ましメッセージ。
- **リマインダー通知**: ブラウザ通知を許可すると、指定時刻までに未記録の場合に通知（タブを開いている間のみ）。
- **データのエクスポート/インポート**: JSONファイルとしてバックアップ・復元が可能。

## 使い方

ビルド不要です。`index.html` をブラウザで開くか、静的ホスティング（GitHub Pages など）にそのまま配置してください。

ローカルで確認する場合:

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。

## プライバシー

すべての記録データは端末のブラウザ内 (`localStorage`) にのみ保存され、外部サーバーには一切送信されません。ブラウザのデータを削除するとサイト上の記録も消えるため、必要に応じてエクスポート機能でバックアップしてください。

## ファイル構成
