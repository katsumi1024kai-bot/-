# 53武器クエスト

宅建の○✕問題で冒険するRPG。魔王ボウキャクの呪いで53の武器（論点）が生き物「ワスレモノ」になった。
草むらで出会い、○✕で正体を見抜いてハンコで契約し、なかまを育てて、試験の日によみがえる魔王を倒す。

あそぶ：https://claude.ai/artifact/PLHfMxUSsxR8nqLcLiCYjr

## あそびかた

- **フィールド**：マスをタップすると歩く（キーボードは矢印／WASD）。草むらを歩くとワスレモノと出会う。「さがす」ですぐ出会える。
- **戦い**：文を読んで、正しければ ○、まちがいなら ✕。正解で1ダメージ、すばやく答えると「会心の一撃」、5連続で FEVER。
- **契約**：弱らせたら「ハンコを おす！」でなかまに。その子の文に正解しつづけると進化（★★ 成体、★★★ 伝説体）。
- **キラ**：なかまの子がキラキラ光って出てくることがある。全部の文をノーミスで答えるとキラ契約。
- **♥**：まちがえると減る。泉で回復。0になると泉にもどされる（失うものはない）。
- **町**：泉（回復）、鍛冶屋（サビ落とし）、番人の館（章ボス・紋章）、看板（合言葉）、修行者（5問勝負）。
- **ライバル カンタ**：「勘でいける」が口ぐせの受験生。3回勝負。
- **魔王城**：紋章5つで封印がとける。本試験と同じ配分の50問、37問正解で勝ち。
- **サビ**：まちがえた文。鍛冶屋でまとめて落とせる。
- **相棒**：★★で会心の時間が1.2倍、★★★で1戦に1回ミスをかばう。
