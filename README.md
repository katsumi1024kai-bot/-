# 53武器クエスト

宅建の○✕問題で戦うバトルRPG。53の武器（論点）を集めて、試験の日によみがえる魔王ボウキャクを倒す。

あそぶ：https://claude.ai/artifact/PLHfMxUSsxR8nqLcLiCYjr

## あそびかた

- 文を読んで、正しければ ○、まちがいなら ✕。正解でボスに1ダメージ。
- すばやく答えると「会心の一撃」。5問連続正解で FEVER（スコア2倍）。
- まちがえると ♥ が減り、その文はあとでもう一度出る。♥ が0になると負け。
- 5つの章（権利・法令・税・業法・その他）をクリアすると魔王城の封印がとける。
  魔王戦は本試験と同じ配分の50問。37問正解で勝ち、14回まちがえると負け。
- まちがえた文は「サビ」になる。サビ落としで取りもどす。
- 武器庫：★ 手に入れた／★★ どの文も最後は正解／★★★ どの文も2回連続正解（伝説）。

## セーブ

自動セーブ。ブラウザ（localStorage）と、ログイン中ならクラウドの両方に保存する。
メニューの「ふっかつのじゅもん」でセーブを文字にして書き出し・読みこみができる（読みこむと今のセーブと合体）。
v1 の記録（経験値・手に入れた武器・まちがえた文）も引き継ぐ。
