# 日々の秘書システム

このディレクトリは、日々の予定・タスクの管理と毎朝のブリーフィングのためのデータ置き場。

## 仕組み

- `tasks.md` が唯一のデータソース。予定やタスクをチャットで伝えると、ここに追記・整理される。
- 毎朝7:30(JST)に自動実行されるRoutine(スケジュールタスク)が `tasks.md` を読み、
  その日の予定・タスクをまとめてプッシュ通知で届ける。
- 個別のリマインダーが欲しい時は、都度チャットでリクエストする(例:「15時の会議の30分前に教えて」)。

## 運用ブランチ

`claude/daily-schedule-secretary-ci4hcm` ブランチで管理。更新のたびにこのブランチへコミット・プッシュする。
